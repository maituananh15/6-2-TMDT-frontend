# 6-2-TMDT Frontend

## Hướng dẫn cài đặt và chạy dự án

### 1. Clone source code

```bash
git clone -b develop --single-branch https://github.com/thaisnek/6-2-TMDT-frontend.git
```

### 2. Di chuyển vào thư mục dự án

```bash
cd 6-2-TMDT-frontend
```

### 3. Cài đặt các thư viện cần thiết

```bash
npm install
```

### 4. Chạy dự án

```bash
npm run dev
```

Sau khi chạy lệnh trên, nhập:

```text
0
```

và nhấn **Enter** để mở ứng dụng trên trình duyệt.

---

## Yêu cầu môi trường

* Node.js >= 18
* npm >= 10

## Công nghệ sử dụng

* ReactJS
* Vite
* JavaScript
* CSS
